** Assignments**

1. Linear Search

- Searches for an element in an array.
- Checks elements one by one.
- Displays the position if the element is found.

Sample Input

5
10 20 30 40 50
30

Sample Output

Element found at position 3

Time Complexity: O(n)
Space Complexity: O(1)

2. Binary Search

- Searches for an element in a sorted array.
- Uses the divide-and-conquer technique.
- Displays the position of the element.

Sample Input

5
10 20 30 40 50
40

Sample Output

Element found at position 4

Time Complexity: O(log n)
Space Complexity: O(1)

3. Bubble Sort

- Sorts array elements in ascending order.
- Compares adjacent elements.
- Counts the total number of swaps.

Sample Input

5
5 3 8 1 2

Sample Output

Sorted array: 1 2 3 5 8
Total swaps: 7

Time Complexity: O(n²)
Auxiliary Space Complexity: O(1)

4. Reverse Array

- Reverses an array using two pointers.
- Swaps the first and last elements.
- Does not use another array.

Sample Input

5
10 20 30 40 50

Sample Output

Reversed array: 50 40 30 20 10

Time Complexity: O(n)
Auxiliary Space Complexity: O(1)

**Mini Project: Student Marks Analyzer**

Description

A C++ application that analyses student marks using arrays and sorting.

Features

- Accepts marks of N students.
- Sorts marks in descending order.
- Displays the top 3 marks.
- Calculates the average marks.

Sample Input

5
78 95 82 67 90

Sample Output

Top 3 Marks:
95
90
82

Average Marks: 82.40

Concepts Used

- Arrays / Vectors
- Sorting
- Loops
- Conditional statements
- Average calculation
